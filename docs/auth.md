# Authentication

Sensitive API routes are protected using [JSON Web Tokens](https://jwt.io/).
Clients must send a valid JWT in the `Authorization` header for the following
paths:

- `/live` and subroutes
- `/risk/*`
- `/jobs/*`

## Token format

Tokens use the `HS256` algorithm and are validated with the shared secret
provided via the `AUTH_SECRET` environment variable.

Example request:

```http
GET /live HTTP/1.1
Host: api.example.com
Authorization: Bearer <token>
```

The middleware verifies the signature and `exp` claim (if present). Requests
without a valid token receive a `401 Unauthorized` response.

For testing and internal scripts, tokens can be generated by signing a payload
with the shared secret using HMAC SHA256.
