Atlik repo specifikacijos generavimą:

1. Perskaityk failą artifacts/repo-survey.md (jis sugeneruotas repo-survey.sh skriptu).
2. Sukurk dokumentą docs/spec.md pagal šį šabloną:
  - Executive summary (10–15 eilučių)
  - Architecture overview
  - Codebase layout
  - Runtime & operations
  - Data model
  - APIs & interfaces
  - Frontend (jei yra)
  - Observability
  - Security & compliance
  - Testing & QA
  - Backlog: Gaps & Recommendations
  - Appendix (nuorodos į artifacts/repo-survey.md)

3. Naudok tik faktus iš artifacts/repo-survey.md.
   Jei kažko trūksta – pažymėk „GAPS/TBD“.

4. Rezultatas turi būti įrašytas į failą docs/specX.X.md.
